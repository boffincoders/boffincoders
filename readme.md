We design and build websites and apps, and run their SEO, for businesses. We also build white-label for agencies.

Every package we maintain, with what it solves and how to install it: **[boffincoders.com/open-source](https://boffincoders.com/open-source)**

## Packages we maintain

| Package | What it solves | Install |
|---|---|---|
| [durable_queue](https://github.com/boffincoders/durable_queue) | Uploads, messages and sync in a Dart or Flutter app that survive no signal, server errors and an app crash: tasks are stored first, retried with backoff and recovered at the next start. MIT. [pub.dev](https://pub.dev/packages/durable_queue) | `dart pub add durable_queue` |
| [fundamental-analysis](https://github.com/boffincoders/fundamental-analysis) | Fundamental analysis in TypeScript with no dependencies: financial ratios, Piotroski F-Score, Altman Z-Score, DCF, Graham Number and valuation multiples. MIT. [npm](https://www.npmjs.com/package/fundamental-analysis) | `npm i fundamental-analysis` |
| [akamai-netstorageapi-typescript](https://github.com/boffincoders/akamai-netstorageapi-typescript) | A TypeScript client and CLI for the Akamai NetStorage HTTP API: upload, download, list, stat, rename and delete, with promises. MIT. [npm](https://www.npmjs.com/package/ts-netstorageapi-akamai) | `npm i ts-netstorageapi-akamai` |

Smaller Flutter packages: [flutter_scale_ruler](https://pub.dev/packages/flutter_scale_ruler) (a scale ruler in feet
and inches) and [curved_nav_bar](https://pub.dev/packages/curved_nav_bar) (a curved bottom navigation bar with a centre
action button).
